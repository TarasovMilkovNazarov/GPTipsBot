# Пример для виртуальной примерки

Показывается в инструкции при выборе «👗 Примерка». Бот склеивает файлы в одну картинку слева направо:

* `person.jpg` — фото человека в полный рост («до»), обязательно
* `clothes.jpg` — фото вещи (товар или скриншот магазина), необязательно — встаёт посередине
* `result.jpg` — результат примерки («после»), обязательно

Если `person.jpg` или `result.jpg` нет, инструкция уходит обычным текстом.
